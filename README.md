# 📖 Diario Emocional - Aplicación Web y Móvil

Aplicación desarrollada para el registro, seguimiento y gestión del bienestar emocional personal, estructurada con un entorno web e integrada para dispositivos móviles mediante **Capacitor**.

## 🚀 Módulos y Funcionalidades Principales

* **Autenticación Segura (`index.php`, `login.php`, `register.php`):** Sistema completo de registro e inicio de sesión de usuarios.
* **Gestión de Entradas y Bitácora:** Módulos de backend para almacenar, consultar y administrar el historial de registros emocionales.
* **Compatibilidad Móvil (Capacitor):** Configuración lista para compilar y desplegar la aplicación web como una app nativa en dispositivos móviles (`capacitor.config.json`).

## 🛠️ Stack Tecnológico

* **Frontend & Interfaz:** HTML5, CSS3, JavaScript (organizado en `/js` y `/css`).
* **Backend:** PHP.
* **Base de Datos y API:** Conexiones y lógica estructurada en `/db` y `/api`.
* **Empaquetado Móvil:** Capacitor (`node_modules`, `capacitor.config.json`).

## 📦 Estructura del Proyecto

* `/api` — Endpoints y lógica de comunicación de datos.
* `/css` & `/js` — Estilos visuales y scripts de interactividad de la interfaz.
* `/db` — Conexión y esquemas de base de datos.
* `/includes` — Componentes reutilizables de la aplicación.
* `capacitor.config.json` — Configuración para el despliegue híbrido/móvil.
* `index.php`, `login.php`, `register.php` — Vistas principales y control de acceso.
